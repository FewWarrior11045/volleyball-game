# 배구 대전

배구 게임 (혼자 AI랑, 또는 둘이서). `index.html`을 열면 바로 실행돼요.

## 조작
| | 왼쪽 | 오른쪽 |
|---|---|---|
| 이동 | D / G | ← / → |
| 점프 | R | ↑ |
| 아래 | F | ↓ |
| 공격 | Z | Enter |

- 공중에서 공격 + 방향키 → 스파이크 방향·세기 조절
- 땅에서 공격 + 좌우 → 다이빙
- Backspace 빠르게 3번 → 맨 처음 화면으로
- 처음 화면 메뉴: 혼자 플레이 / 같이 플레이 / 조작 방법 (↑↓ 또는 R/F로 고르고 Z/Enter)
- 혼자 플레이: Z = 왼쪽, Enter = 오른쪽에서 플레이 → 난이도 → 캐릭터 (AI 캐릭터는 안 고르면 랜덤)
- 스킬: 왼쪽 Shift, 오른쪽 숫자패드 5 또는 ; (스파이크를 맞혀 마나를 채우면 사용 — 기본 5칸, 키다리·김지연은 3칸)
- 시작 전 캐릭터 선택: 왼쪽 D/G + Z, 오른쪽 ←/→ + Enter

## 이미지 바꾸기
`assets` 폴더에 아래 이름으로 넣으면 자동으로 적용돼요. (없으면 기본 그림)
- `background.png` — 배경 (864×608 추천)
- `player1.png`, `player2.png` — 선수 (배경 투명 PNG, **오른쪽을 보는** 그림)
- `ball.png` — 공 (선택)
